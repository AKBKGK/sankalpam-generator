NEW FEATURES ADDED:
──────────────────

1. EMAIL THIS PDF ONCE (One-time Email Feature)
   ✓ New button: "📧 Email This PDF Once" on both Saṅkalpam and Tarpaṇam tabs
   ✓ User enters email → PDF sends immediately (no subscription/confirmation needed)
   ✓ Logging: Only tracked if user is NOT a daily subscriber
   ✓ Non-subscribers: logged to OneTimeEmails sheet (for usage analytics)
   ✓ Daily subscribers: PDF sent, no logging (already tracked in Subscribers sheet)

2. PDF DOWNLOAD TRACKING (Anonymous Analytics)
   ✓ Automatic tracking when users click "Print / Save as PDF"
   ✓ Automatic tracking when users click "📱 Compact PDF (WhatsApp)"
   ✓ Anonymous logging (no email required, doesn't interrupt UX)
   ✓ Logged to OneTimeEmails sheet with: Date | [blank] | Type | Action
   ✓ Action types: PrintPDF or CompactPDF
   ✓ Helps analyze which format users prefer

CODE.GS (Backend - Google Apps Script)
──────────────────────────────────────
✓ New function: emailPdfOnce_(req)
  - Validates email address
  - Decodes Base64 PDF and sends via GmailApp
  - Checks if email is in Subscribers sheet
  - Only logs non-subscribers to OneTimeEmails

✓ New function: logPdfDownload_(docType, action)
  - Logs PDF downloads anonymously
  - Records: timestamp, doc type (sank/tarp), action (PrintPDF/CompactPDF)

  - if (req.action === 'emailPdfOnce') → calls emailPdfOnce_(req)
  - if (req.action === 'logPdfDownload') → calls logPdfDownload_()

SHEET STRUCTURE (OneTimeEmails):
────────────────────────────────

Column Headers: Date | Email | Type | Status

One-time Email Logs:
  Date: ISO timestamp
  Email: user's email address
  Type: 'sank' (Saṅkalpam) or 'tarp' (Tarpaṇam)
  Status: 'Sent' (only logged if NOT a daily subscriber)

PDF Download Logs:
  Date: ISO timestamp
  Email: [blank/empty]
  Type: 'sank' (Saṅkalpam) or 'tarp' (Tarpaṇam)
  Status: 'PrintPDF' or 'CompactPDF'
