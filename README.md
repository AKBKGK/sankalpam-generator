# Saṅkalpam Generator

A single-page, offline-capable Saṅkalpam generator (Devanagari + IAST).
Pañcāṅgam is calculated in the browser from the chosen date.

- Open `index.html` in any browser, or visit the hosted site.
- No sign-in; nothing is sent to a server.
- Pañcāṅgam values are approximate. Please verify with your own pañcāṅgam.
